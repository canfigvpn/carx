# دفترچه هوشمند پژو ۲۰۶ — PWA

## امکانات
- ذخیره خودکار اطلاعات داخل گوشی با IndexedDB
- برنامه سرویس بر اساس کیلومتر و ماه
- هشدار نزدیک موعد: ۵۰۰۰ کیلومتر یا ۱۵ روز مانده به موعد
- وضعیت سررسید گذشته با رنگ قرمز
- ثبت سوابق سرویس، تاریخ، کیلومتر، هزینه و یادداشت
- ثبت سوخت‌گیری
- خروجی و بازیابی کامل JSON
- پشتیبان‌گیری خودکار Google Drive پس از اتصال حساب
- نصب به شکل PWA و اجرای آفلاین پس از بارگذاری اولیه

## اجرای برنامه
PWA و Service Worker باید روی HTTPS یا localhost اجرا شوند؛ اجرای مستقیم فایل `index.html` از پوشه گوشی برای نصب و آفلاین کامل مناسب نیست.

راه ساده:
1. فایل‌های این پوشه را در یک مخزن GitHub قرار بده.
2. در مخزن برو به Settings → Pages.
3. گزینه Deploy from a branch را انتخاب کن، شاخه `main` و پوشه `/root` را ذخیره کن.
4. پس از انتشار، نشانی HTTPS سایت را با Chrome یا Samsung Internet باز کن و از منوی مرورگر «افزودن به صفحه اصلی / نصب برنامه» را بزن.

## فعال‌سازی Google Drive
اتصال ابری به شناسه OAuth نیاز دارد. شناسه و رمز عبور حساب گوگل را داخل برنامه وارد نکن؛ فقط Client ID عمومی مخصوص وب را وارد کن.

1. وارد Google Cloud Console شو: https://console.cloud.google.com/
2. یک پروژه بساز یا انتخاب کن.
3. از APIs & Services → Library، گزینه Google Drive API را فعال کن.
4. از Google Auth Platform، صفحه رضایت OAuth را پیکربندی کن. نوع کاربر و کاربران آزمایشی را مطابق حساب خودت تنظیم کن.
5. از APIs & Services → Credentials، یک OAuth Client ID از نوع Web application بساز.
6. در Authorized JavaScript origins، دامنه HTTPS منتشرشده را اضافه کن؛ مسیر صفحه را وارد نکن. برای مثال `https://USERNAME.github.io`
7. Client ID ساخته‌شده را کپی کن.
8. برنامه را باز کن، در تنظیمات بخش Google Drive، Client ID را وارد و ذخیره کن؛ سپس «اتصال Google Drive» را بزن و مجوز را تأیید کن.

برنامه با مجوز `drive.file` فقط به فایل‌هایی که خودش ایجاد کرده دسترسی می‌گیرد و یک فایل با نام `Peugeot206-Backup.json` در Drive می‌سازد/به‌روزرسانی می‌کند. هر تغییر جدید بعد از اتصال فعال، با کمی تأخیر همگام می‌شود. برای همگام‌سازی بعد از بازشدن دوباره برنامه، در صورت درخواست مجوز/اتصال را دوباره انجام بده.

## نکات مهم پشتیبان‌گیری
- داده‌های اصلی داخل مرورگر گوشی هستند؛ حذف داده‌های سایت/مرورگر می‌تواند آن‌ها را پاک کند.
- همگام‌سازی Google Drive فقط پس از تنظیم Client ID و تأیید دسترسی کار می‌کند.
- قبل از پاک‌کردن داده‌های مرورگر یا تعویض گوشی، یک فایل JSON هم دانلود کن یا مطمئن شو نسخه Drive به‌روز شده است.
- نسخه اول، همگام‌سازی یک‌طرفه از گوشی به Drive دارد. بازیابی از فایل JSON با دکمه «بازیابی فایل» انجام می‌شود.
- برای بازیابی از Drive، فایل `Peugeot206-Backup.json` را از Google Drive دانلود و در برنامه وارد کن.

## ساختار پروژه
- `index.html`: رابط کاربری
- `style.css`: ظاهر واکنش‌گرا
- `app.js`: منطق، IndexedDB، سوابق، پشتیبان‌گیری
- `manifest.webmanifest`: مشخصات نصب PWA
- `sw.js`: کش آفلاین
- `config.js`: شناسه OAuth (در صورت تمایل می‌توان Client ID را اینجا هم قرار داد)
- `icon.svg`: آیکن برنامه
